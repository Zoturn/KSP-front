# ksp-frontend — React E-Commerce UI

General info for this repo. Specific, enforceable conventions live in this repo's own
`.claude/rules/` (`frontend.md`, `testing.md`). They are **path-scoped** — each loads
automatically when matching files are read or edited, and travels with the repo.

## Stack

- **React** + **Vite** + **TypeScript**
- **TanStack Query** — all server state (fetching, caching, invalidation)
- **Tailwind CSS** — utility-first styling (new to the author)
- **Generated GraphQL client** — types and typed hooks generated by **graphql-codegen** from
  the backend's committed `schema.gql`
- **Vitest** + **React Testing Library** — component and hook tests

## The backend connection

The backend is **GraphQL-only** — one endpoint, `POST /graphql`. There is no REST API and no
OpenAPI spec.

This repo never hand-writes API types. It consumes `ksp-backend`'s committed **`schema.gql`**
and **generates** typed operations from it. If the backend schema changes, the frontend fails
to compile — that is the intended safety net.

```
backend decorators  →  schema.gql (committed)  →  graphql-codegen  →  typed hooks  →  components
```

Generate from the **committed file, never a live URL** — introspection is disabled in
production, so a URL-based config works in dev and fails in CI.

## Two GraphQL habits that differ from REST

- **Errors arrive with HTTP 200.** Never branch on status. Check the `errors` array and read
  `errors[0].extensions.code`. `data` and `errors` can coexist — render what resolved.
- **Select only the fields you render.** Over-selecting silently costs backend work.

## Layout (target)

```
src/
  main.tsx / App.tsx
  api/            # generated client (do not edit by hand) + axios instance & interceptors
  features/       # auth, catalog, cart, checkout, orders, admin — each with components/hooks
  components/     # shared presentational components
  lib/            # helpers (money formatting, storage)
  routes/         # route definitions & guards
LEARNING/         # teaching notes (Tailwind, TanStack Query) — LOCAL ONLY, gitignored
```

## Common commands

```bash
npm run dev            # Vite dev server
npm run build          # production build
npm run test           # Vitest
npm run generate:api   # regenerate the API client from the backend spec
```
